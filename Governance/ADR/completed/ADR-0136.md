# ADR-0136: Research Routes Fail Closed on an Unbound Provider; No Synthesized Answers

**Status:** Accepted

## Context
Both research routes were wired to lib/hologram-ai.ts, a thirty-line class that documented itself as a stub. Its generate method ignored its prompt and returned the literal string '[PhaseMirror / HologramAI]: Synthesis complete. Missing actual compute binding for agent phasemirror.', logging 'Vibe claim detected. Simulating response.'. Its generateJSON method ignored its prompt entirely and returned a hardcoded object whose overview read 'Overview mechanism missing. Replaced vibe claim.' and whose single key theme was named 'Missing Binding'. POST /api/research/chat therefore returned plausible prose and POST /api/research/synthesize returned a fixed object, neither produced by a model, and both indistinguishable to a client from real output. The synthesize route did not even ask for the JSON schema the sibling foundry-web-example package requested, so the hardcoded object was the only shape any caller could have received. The mechanism to restore was already declared: @google/genai is a production dependency, resolved to 2.23.0 in the lockfile, and .env.example documents GEMINI_API_KEY as the required key. Because the package is untracked, no version control history retains the deleted stub, so its exact behavior is recorded here.

## Decision
lib/hologram-ai.ts is deleted rather than completed, because no wire protocol for the HOLOGRAM_ENDPOINT it named exists on tree and inventing one would be the same defect at a different layer. The mechanism is the declared one: lib/research-provider.ts binds @google/genai, restores the structured chat session with history that the stub had replaced with string concatenation, and restores the responseMimeType request the stub never made. When GEMINI_API_KEY is absent the client receives a typed research-provider-unbound error with HTTP 503 and no result field. No code path returns a stand-in answer, a placeholder string, or an empty object standing in for a model response. Every string these routes return is text a model produced.

## Consequences
* A client can no longer receive a fabricated synthesis, and an unbound deployment fails visibly instead of answering
* Chat regains a real session with prior turns as history, rather than a prompt built by concatenating the system instruction onto the last message
* lib/hologram-ai.ts has no remaining importer, so no route can reach the fabrication
* The research routes remain unregistered conformance capabilities: this record states the mechanism, it does not establish the capability under ADR-0129
