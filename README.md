# Founders-OS

**Founders-OS** is an operating system for decentralized autonomous governance, built around sovereign agents and mathematical constraints.

## Overview
This package contains the core components for the Founder OS MCP (Model Context Protocol) Server, AI agent instructions, the Ξ-Constitution, and other foundational governance documents.

## Repository Layout
- `Founder OS MCP Server.md`: Detailed specification for the MCP server.
- `AGENTS.md`: Persona and system instructions for AI agents participating in the ecosystem.
- `Ξ-CONSTITUTION.md`: The core sovereign constitution governing interactions.
- `src/`: Source code for the Founders-OS application.

## Getting Started
Please read the [Founder OS MCP Server](Founder OS MCP Server.md) document to understand the server architecture.
