# ADR-0116: tokio Runtime Dependency Removed from ri1-core

**Status:** Accepted

## Context

`crates/ri1-core/Cargo.toml` listed `tokio = { version = "1", features = ["rt-multi-thread", "macros"] }`. No `async fn`, `#[tokio::main]`, or `tokio::` prefix exists anywhere in `ri1-core` or any downstream crate in the workspace. The dependency added compile time and transitive dependencies with zero benefit.

## Decision

Remove `tokio` from `ri1-core/Cargo.toml`. All orchestrator methods are synchronous. If async orchestration is needed in the future, re-add tokio via a new ADR with explicit justification.

## Consequences

- Compile time reduced (eliminates tokio + mio + hashbrown + tracing-appender transitive chain)
- No behavioral change; all synchronous code paths unaffected
- Future async work requires re-adding tokio via ADR process
- No downstream crate depends on tokio from ri1-core
