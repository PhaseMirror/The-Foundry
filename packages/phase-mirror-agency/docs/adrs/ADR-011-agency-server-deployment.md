# ADR 011: Agency Server — Node.js Orchestration & Hybrid Deployment

## Status
Proposed

## Context
We need a unified deployment package for the Agency that can be easily installed in a server's home directory. While the core "Cold Machine" logic is best served by Rust, the high-level API orchestration, session management, and external integration (OpenAI/Gemini endpoints) benefit from the rich ecosystem of Node.js.

## Decision
We will implement a **Hybrid Agency Server** in `Phase Mirror/agency-server/`.

### 1. Hybrid Architecture
- **Orchestration Layer (Node.js)**:
    - Provides the Express-based REST API.
    - Handles authentication and rate limiting.
    - Orchestrates the "Mission Sequence" (Genius → Guardian → Examiner).
- **Execution Layer (Rust Binaries)**:
    - Compiled ensemble harnesses (Ataraxia, Finton, etc.) are bundled in the `bin/` directory.
    - Node.js dispatches deterministic tasks to these binaries via `child_process`.

### 2. Deployment Package Structure
The package will be a self-contained directory:
```text
agency-server/
├── package.json
├── src/            # Node.js API logic
├── bin/            # Pre-compiled Rust Ensemble Binaries
├── config/         # Risk Signatures & API Keys
└── start.sh        # Deployment entry point
```

### 3. "Just Like Gemini" Integration
The Node.js server will leverage the `@google/generai` or similar SDKs to act as a bridge, allowing the Agency to augment its deterministic responses with probabilistic "Creative Synthesis" when requested.

## Implementation Guidelines
- **Portability**: The server must run without global dependencies (other than Node.js).
- **Integrity**: Every response from the Node.js layer MUST include the `witness_hash` generated by the underlying Rust execution binaries.

## Consequences
- **Positive**: Combines the developer-friendly nature of Node.js with the mathematical rigor of Rust; easy deployment to standard VPS/Shared environments.
- **Negative**: Requires managing binary compatibility for the `bin/` directory across different server architectures (Linux x64, ARM, etc.).
