## 1. Context
Standard adaptive optimizers (Adam, AdamW) operate purely on the gradient of the task loss $\nabla_\theta f(\theta)$. They lack awareness of the multiplicity-theoretic structure and the zeta-guided potentials defined in the Z-MOD framework. We need an optimizer that integrates the continuous gradient flow with the complex-analytic geometry of the zeta function.

## 2. Decision
We implement **ZMODAdam**, a hybrid optimizer that extends the Adam algorithm with a zeta-potential gradient.

The update rule for parameters $\theta$ is:
$$\theta_{t+1} = \theta_t - \eta \cdot \text{Adam}(\nabla_\theta f(\theta) + \lambda \nabla_\theta Z_0(\theta, \pi))$$

Where $Z_0(\theta, \pi)$ is the base zeta potential:
$$Z_0(\theta, \pi) = \text{Re} \ln | \zeta(s(\theta, \pi)) | + \epsilon$$

The analytic gradient $\nabla_\theta Z_0$ is pulled back through the embedding:
$$\nabla_\theta Z_0 = \text{Re} \left[ \frac{\zeta'(s)}{\zeta(s)} \cdot i a \right] \cdot \frac{2}{n} \theta$$
(valid for the unclipped region $\phi(\theta) < \Phi_{max}$).

## 3. Alternatives Considered
- **Zeta Scaling (ZetA):** Using zeta values merely as a scalar learning rate multiplier. Rejected as it ignores the rich directional information available in the logarithmic derivative $\zeta'/\zeta$.
- **Direct SGD with Zeta:** Rejected because adaptive second-moment estimation (Adam) is empirically superior for the complex landscapes of neural networks.

## 4. Dependencies
- ADR-010: Canonical Embedding Specification
- PyTorch (or similar deep learning framework)

## 5. Risks
- **Gradient Exploding/Vanishing:** Near the zeros of $\zeta(s)$, $\zeta'/\zeta$ can become very large. This requires the use of the stability constant $\epsilon$ and potentially gradient clipping.
- **Computational Overhead:** Evaluating $\zeta(s)$ and $\zeta'(s)$ at every step increases training time. This is mitigated by using fast approximations or precomputed tables for $\zeta$.

## 6. Consequences
- **Positive:** Enables "zeta-guided" search in parameter space; provides a mechanism for parameters to respond to arithmetic resonance.
- **Negative:** Introduces additional hyperparameters ($\lambda$, $\epsilon$) that require tuning.
