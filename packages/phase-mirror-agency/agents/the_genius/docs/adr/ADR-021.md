## 1. Context
While ZMODAdam (ADR-020) handles high-dimensional updates, certain critical components—such as prime-weight fitting and safety projection (ADR-011)—require small-scale, second-order optimization for precision and stability.

## 2. Decision
We refine the **ZMODAdam State Transition** to incorporate **Levenberg-Marquardt (LM)** for specific sub-tasks:
1. **Zeta Geometry Factor ($Z_t$):** We formally introduce $Z_t$ as a factor that modulates the gradient in the embedded space: $g^{(Z)}_t = f_Z(g_t, Z_t)$.
2. **LM-Tuner:** For low-dimensional weight vectors (e.g., PrimeWeightNet, $P \le 12$), we use the Levenberg-Marquardt algorithm to solve constrained nonlinear least squares, ensuring data fit aligns with contractivity.
3. **Portal Alignment:** Use LM to align "duplicated signal portals" (original vs. regularized paths) by minimizing the least-squares difference between their outputs.
4. **Damping Lever:** Use LM's damping parameter $\lambda$ to avoid overshooting into non-contractive regimes.

## 3. Alternatives Considered
- **Pure SGD/Adam:** Rejected for critical components because it can be slow to converge on complex, highly curved surfaces like those found in zeta-geometry.
- **Newton's Method:** Rejected due to sensitivity to non-convexity; LM provides a safer interpolation between gradient descent and Gauss-Newton.

## 4. Dependencies
- ADR-020: ZMODAdam Core Design
- LM algorithm implementation (e.g., `scipy.optimize.least_squares` or custom PyTorch-LM)

## 5. Risks
- **Jacobian Complexity:** LM requires computing or approximating the Jacobian, which might be expensive for larger parameter sets.
- **Tuning Damping:** Incorrect damping values can lead to slow convergence or instability.

## 5. Implementation & Verification

### 5.1 Target Artifacts
- **Module:** `src/zmod/optim/lm_tuner.py`
- **Updated Optimizer:** `src/zmod/optim/zmod_adam.py` (with LM hooks)

### 5.2 Promotion Criteria (Proposed -> Accepted)
| Criteria Type | Description | Target / Threshold |
| :--- | :--- | :--- |
| **Precision** | Convergence on prime-weight fitting task | < 1e-6 RMSE |
| **Stability** | Maintenance of contractivity bound | sup‖m′ₜ‖ ≤ 1.21 |

## 6. Consequences
- **Positive:** High-precision tuning of core architectural weights; better alignment between theory and implementation.
- **Negative:** Increased mathematical and computational complexity in the optimizer loop.
