# ADR-001: Metrics and Evidence Policy

- Status: accepted

## 1. Context
Research in Zeta-guided optimization often relies on high-level theoretical coherence. To ensure production-grade quality and scientific rigour, we need a formal policy for what constitutes "evidence" of success and which metrics are primary.

## 2. Decision
We adopt the following evidence standards:
1. **Numerical Validation:** Every canonical "cell" or conjecture must be backed by at least one reproducible numerical result (Validation-First Gate).
2. **Ablation Studies:** To claim "zeta-specificity," we must perform ablations that replace the Riemann zeta function with generic structured oscillations or noise.
3. **Primary Metrics:**
    - Training Loss/Accuracy (MNIST/CIFAR-10)
    - Convergence Rate (iterations to threshold)
    - Stability (variance across seeds)
    - Spectral Alignment (GUE sine kernel approximation)

## 3. Alternatives Considered
- **Heuristic Success:** Relying on visual inspection of learning curves. Rejected as insufficient for "production-grade" claims.
- **Purely Theoretical Proofs:** While valuable, they are not sufficient for an implementation plan.

## 5. Risks
- **Metric Gaming:** Optimizing for a specific benchmark rather than the underlying theory.
- **Computational Cost:** Running full ablation matrices on large datasets.

## 5. Implementation & Verification

### 5.1 Target Artifacts
- **Module:** `src/zmod/metrics.py`
- **Report:** `results/ablation_matrix.md`

### 5.2 Promotion Criteria (Proposed -> Accepted)
| Criteria Type | Description | Target / Threshold |
| :--- | :--- | :--- |
| **Statistical** | P-value for Zeta vs. Ablation | < 0.05 |
| **Reproducibility** | Artifacts produce same result on 3 seeds | Identical curves |

## 6. Consequences
- **Positive:** High confidence in results, clear path to peer-reviewed publication.
- **Negative:** Slower iteration speed due to rigorous testing requirements.
