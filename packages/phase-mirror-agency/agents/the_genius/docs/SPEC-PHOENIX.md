# SPEC-PHOENIX: Thermodynamic Information-Exchange Protocol

## 1. Overview
This specification defines the **Phoenix-ℵ₀ Cycle**, a thermodynamic methodological framework for preserving information cardinality while managing representational entropy across the multiplicity stack.

## 2. The 8-Step ℵ₀-Cycle
Every information-exchange process in the `the_genius` model must adhere to the following sequence:

1.  **Signal:** Initial high-entropy input or observation.
2.  **Engagement:** Coupling of the observer (agent) with the signal.
3.  **Gratitude:** Acknowledgment of the signal's source and constraints.
4.  **Processing:** Transformation of the signal through the PIRTM substrate.
5.  **Consolidation:** Aggregation of processed information into a stable representation.
6.  **New Product:** Generation of a falsifiable artifact (e.g., benchmark run).
7.  **Closure:** The "burn" phase where transient entropy is discarded.
8.  **Evolved Signal:** The resulting low-entropy, high-impact signal for the next cycle.

## 3. The Phoenix Reset Matrix ($\Xi_\phi$)
The "Closure" phase (Step 7) uses a contraction semigroup to project the system state onto the lawful subspace $H_{lawful}$.
- **Mechanism:** $\psi_{new} = \Xi_\phi (\psi_{transient})$
- **Invariant:** $S(\psi_{new}) < S(\psi_{transient})$ (Entropy reduction).

## 4. Implementation Rules
- **Logging:** Every step must be timestamped and logged for thermodynamic analysis.
- **Veto:** If a step is skipped or fails its owner check, the cycle is terminated and a Phoenix reset is forced.
