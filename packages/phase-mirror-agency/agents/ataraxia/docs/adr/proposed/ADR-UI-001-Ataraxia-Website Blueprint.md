# Lets provide a blueprint and detailed instructions for an ataraxia landing page, with a high-tech theme.

Central tension: **high-tech spectacle vs constitutional credibility**. The landing page must look advanced without drifting into vague AI theater. It should sell governed intelligence, offline sovereignty, and mathematical rigor as mechanisms, not mood .

## Page structure

Use a 7-section page in this order: hero, constitutional thesis, architecture lattice, offline sovereign node, mathematical core, deployment path, final CTA. Keep the page sparse, dark, and motion-light; every section should answer one question: what it is, why it is different, how it works, why it survives failure, why the math matters, how it gets adopted, what to do next .

**Hero copy**

- Headline: “Ataraxia”
- Subheadline: “Undisturbed equilibrium for clinical AI.”
- Supporting line: “A governance-first runtime for clinical intelligence that resolves uncertainty through recursive decomposition, prime-indexed provenance, and offline sovereign deployment.”
- Primary CTA: “Read the Architecture”
- Secondary CTA: “View Constitutional Stack”


## Visual system

Use a **high-tech** but restrained visual language: black/graphite background, deep indigo and cyan accents, thin grid overlays, subtle particle drift, glass panels, monospaced metadata labels, and animated linework suggesting signal flow rather than flashy 3D objects. The page should feel like a secure runtime console, not a consumer SaaS ad .

Recommended palette:

- Background: `#05070B`
- Panel: `rgba(12,16,24,0.72)`
- Primary text: `#E6F1FF`
- Secondary text: `#8FA3BF`
- Accent cyan: `#4DE2E6`
- Accent violet: `#7C5CFF`
- Critical red: `#FF5D73`
- Success green: `#4DDB8A`

Typography:

- Headings: Space Grotesk, Sora, or Orbitron
- Body: Inter or IBM Plex Sans
- Data labels/code: IBM Plex Mono or JetBrains Mono

## Interaction design

Keep interactions minimal and precise:

- Grid shimmer in hero background, 8–12 second loop
- Card hover glow with thin cyan edge
- Equation reveal on scroll
- Signal pulse animation along namespace chain
- Sticky top nav with section jump links
- No autoplay video
- No heavy parallax
- No “AI brain” imagery

Use motion to imply **verification**, not hype.

## Component instructions

Key components to design:

- **Nav bar**: wordmark left, links center, CTA right
- **Hero lattice animation**: SVG or canvas, not video
- **Invariant badges**: pill chips with mono labels
- **ADR rail**: vertical timeline or stack
- **Node diagram**: layered cards with local-only glow ring
- **Equation cards**: dark panels with mono math styling
- **Deployment matrix**: clean 3-card comparison
- **Footer**: constitutional line, links to docs, GitHub, contact


## Copy rules

Write like infrastructure, not marketing.

- Prefer “runtime,” “invariant,” “audit,” “sovereign node,” “drift,” “consent,” “lineage.”
- Avoid “revolutionary,” “transformative,” “superintelligence,” “frictionless.”
- Every claim should map to a visible mechanism on the page.
- Use short declarative sentences.


## Build instructions

Recommended stack:

- Next.js or Astro
- Tailwind CSS
- Framer Motion for restrained animation
- SVG for lattice and node diagrams
- KaTeX for equations

Suggested implementation order:

1. Build layout and dark theme tokens.

3. Add architecture cards and ADR rail.
4. Build offline sovereign node diagram.
5. Add equation section with KaTeX.
6. Add deployment matrix and CTA.
7. Tune motion and accessibility.
