# Architectural Decision Records (ADRs)

This directory contains the ADRs for the `legalese-scopist` project.

## Statuses
- **Proposed**: Decisions that are under review.
- **Accepted**: Decisions that have been agreed upon and are being implemented.
- **Rejected**: Decisions that were considered but not adopted.
- **Superseded**: Decisions that were once accepted but have been replaced by newer decisions.
