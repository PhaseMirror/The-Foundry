# ADR-0001: Record Architectural Decisions

## Status
Accepted

## Context
We need a way to record architectural decisions for the `legalese-scopist` project to ensure transparency, traceability, and consistency as the project grows.

## Decision
We will use Architectural Decision Records (ADRs) as described by Michael Nygard. ADRs will be stored as Markdown files in the `docs/adr` directory.

## Consequences
- Architectural decisions will be documented and version-controlled.
- Team members can understand the "why" behind technical choices.
- The history of the project's architecture will be preserved.
