# Citizen Gardens 🌿

> **Multiplicity, Social Physics, and Local Sovereignty.**

Citizen Gardens is an experimental platform exploring the intersection of **Social Physics**, **Multiplicity**, and **Sustainable Localism**. It provides tools for communities to model, govern, and sustain local ecosystems using formal-proof-backed principles.

## 🌟 Vision

Our mission is to empower communities with the technical substrate required for true local sovereignty. By combining advanced predictive modeling (Social Physics) with decentralized governance (Multiplicity), we create resilient, flourishing "gardens" of human cooperation.

## 🚀 Features

*   **Social Physics Lab:** Model community interactions and resource flows.
*   **Multi-Credit System:** A flexible, proof-backed value exchange engine.
*   **Community Dashboard:** Real-time visibility into local sustainability metrics.
*   **Moral Physics Engine:** Formalizing ethical constraints within community state transitions.

## 🛠️ Technology Stack

*   **Frontend:** React (TypeScript), Vite, TailwindCSS, Three.js (for 3D visualizations).
*   **Backend:** Node.js (Express) with SQLite integration for local-first persistence.
*   **Governance:** Integrated with the Multiplicity governance floor.

## 🏁 Getting Started

1.  **Install dependencies:**
    ```bash
    npm install
    ```
2.  **Run in development:**
    ```bash
    npm run dev
    ```
3.  **Build for production:**
    ```bash
    npm run build
    ```
