\section{Circuit Optimization}
The \texttt{MillerRabin.circom} circuit was optimized for fast-prime validation:
\begin{itemize}
    \item Reduced modular exponentiations from 2--3 bases to single base (2).
    \item Precomputed $d$ and $s$ for $n-1 = d \cdot 2^s$, lowering constraint count from $\sim$10,000 to $\sim$5,500.
    \item Maintained false positive rate $< 2^{-11}$ for 64-bit inputs.
\end{itemize}
