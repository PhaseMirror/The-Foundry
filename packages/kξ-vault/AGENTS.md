What each pair is not
R4 router × LexLean. R4’s “reversible lexical address” is a codec inside a language-model crate (uor-r4.unicode-lexical-runs/1). LexLean’s lexicon is a closed package graph with axiom policy. A lexical run is not a .lex.tex module. Generating Lean from R4 routes is an unseated new foundation.
R4 router × PrismPM. PrismPM forbids handwritten application Lean and target-specific app code. R4 is handwritten Rust plus learned artifacts. Putting the router behind a Foundry View would make PrismPM publish a research LM. That is Object (B) compute fabric, already refused for year one. prismpm_is_compiler() = true. prismpm_is_control_plane() = false.
R4 router × PIRTM. PIRTM Accept requires Wire.adr005 and a nonzero commitment. A prime-route choice is not that commitment. Wrapping R4 weights in CRMF stores a corpus. It does not make the corpus a router, a signer, or an Accept.
R4 router × Phase Mirror. If the packet offers R4 as the agent, the coat is proposesLlm → stopLlmPath. The Gemma-titled tree fails on the same gate without a hearing. If the packet offers R4 as the patient, Phase Mirror may name intent vs incentive and stop on missing metric. It does not patch the router.
LexLean × PIRTM. LexLean checks and lowers predicates. PIRTM decides a hide. KΞ says control-plane predicates in KXiVault.lex.tex or they are not law. PIRTM is not a LexLean glossary. Compiling a vault module does not seat 049c.
LexLean × Phase Mirror. PhaseMirrorAgent.lean is handwritten civic Lean, no mathlib, no sorry. That is the L0-L bench style. PrismPM’s law is the opposite for application behavior: no handwritten Lean. Two Lean regimes. Do not merge them into one Lex.lean.
PrismPM × Phase Mirror. Compiler vs diagnostic loop. PrismPM can publish a View of flags the loop already named. It cannot run the five steps. The five steps cannot compile a .holo.
PrismPM × PIRTM. Sign/verify adapters are tooling. They are not the two distinct cryptographic identities required to Accept. One foundry-key invoked twice is one keyboard.
Phase Mirror × PIRTM. Already seated: Feedback is not a rekey oracle. A red gate is a non-event. A new period is a new key. The agent does not close a receipt.
