\section{Central tension}
Stated intent: remember document bytes so they cannot be quietly rewritten, and require two hands before a bind.
Operating incentive: treat a local hash, a portal View, or two PrismPM adapter calls as the second seat.
A vault that self-signs is K1 wearing a K2 coat. A compiler invoked twice from one credential slot is one keyboard. A published Pages asset that carries the signable bytes is a second store, not a View.
Secondaries tensions, named: digest accuracy versus public-asset compliance; handwritten Lean velocity versus generated-only application safety; open local CLI versus hosted vault APIs.
