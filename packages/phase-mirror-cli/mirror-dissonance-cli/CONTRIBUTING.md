# Contributing to Phase Mirror Oracle CLI

Thank you for your interest in contributing to the Phase Mirror Oracle CLI! We welcome contributions that help improve AI governance diagnostics.

## Code of Conduct
By participating in this project, you agree to abide by the terms of the **Ξ-Constitution**.

## How to Contribute
1. **Report Bugs**: Use the GitHub Issues tracker to report bugs.
2. **Feature Requests**: Open an issue to discuss new rules or features.
3. **Pull Requests**:
   - Ensure your code follows the "Governance-as-Compilation" principle.
   - All new scanners must implement the `Scanner` trait.
   - All new logic must adhere to the fail-closed model (ADR-005).
   - Ensure `cargo test` and `cargo check` pass.
