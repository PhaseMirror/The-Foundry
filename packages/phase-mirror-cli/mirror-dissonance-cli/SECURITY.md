# Security Policy

## Supported Versions
We only support the latest version of the Phase Mirror Oracle CLI.

## Reporting a Vulnerability
If you discover a security vulnerability, please report it immediately via the authorized Multiplicity Foundation channels.

**Do not open a public issue.**

All reports must be submitted according to the protocols defined in the **Ξ-Constitution**.

### Fail-Closed Principle
This tool is designed to fail-closed. If you find a way to bypass the L0/L1 gates or cause a silent failure, this is considered a critical security vulnerability.
